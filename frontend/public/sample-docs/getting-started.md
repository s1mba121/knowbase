# Getting started with Acme

Welcome to Acme. This guide covers the basics your customers ask about most often.

## Creating an account

1. Go to https://app.acme.example/signup
2. Enter your work email and choose a password with at least 8 characters.
3. Confirm your email within 24 hours.

## API keys

API keys authenticate requests to the Acme REST API.

### Create a key

Open **Settings → API Keys → Create key**. Copy the key immediately — it is shown only once.

### Rotate API keys

From **Settings → API Keys**, click **Rotate** next to the key you want to replace.

- The new key is active immediately.
- The old key remains valid for a **24-hour grace window**.
- You can keep both keys during migration.

### Rate limits

Free workspaces are limited to **60 requests per minute**. Pro workspaces get **600 requests per minute**.

## Billing

Acme bills monthly on the day you subscribed. You can change plans under **Settings → Billing**. Downgrades take effect at the end of the current period.

## Support

Email support@acme.example or use the in-app chat. Average first response time is under 4 business hours.
